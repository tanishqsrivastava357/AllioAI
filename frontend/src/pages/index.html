What is AllioAI?

AllioAI is a unified workspace for chat, research, creative work, file analysis, and projects. It helps you go from rough thought to useful output without switching tools.

Is my data private?

Your data is encrypted in transit and is not used to train models by default. You control memory and can clear your data through the product. See our Privacy Policy for details.

Does AllioAI support code and API access?

Code Workspace is coming soon, with explain, fix, and run workflows. API access is on the roadmap; contact us if you want to hear when it launches.

Can I use AllioAI on mobile?

Yes. The responsive web app works across phones, tablets, and desktop, with project state synced to your account. Native apps are planned.

Can I cancel my Pro plan?

Yes. You can cancel at any time from your account. Your plan remains active through the current billing period, and there are no long-term contracts.

What files can I upload?

AllioAI supports common documents, PDFs, images, and spreadsheets. Upload limits depend on your plan and may change as the product evolves.

Can I access AllioAI via API?

Currently no, however we are trying to build API access and it might be available soon.

Can I export my data?

Yes, you can export your data using Account Settings in the AllioAI App.

Does AllioAI support team/collaboration?

Yes, but it differs on your plan. Find out if your plan supports it here.
